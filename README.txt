# StudyNepal AI — starter website

## Open on Android / GitHub
1. Extract this ZIP on your phone.
2. Upload `index.html` and the `assets` folder to a GitHub repository.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Open the Pages URL after deployment.

## Included
- Responsive colorful landing page
- Study feature cards and pricing
- Subscription modal with the supplied eSewa QR image
- Transaction reference + email form (front-end demo only)

## Important — before real payments or AI
This is a frontend starter, NOT a production payment system.
- The form does not send or store requests and does not verify payment.
- Do not activate Premium from a screenshot or a typed transaction ID alone.
- Confirm the QR belongs to the account holder who has authorized its public use.
- Use an approved merchant/payment integration and secure server-side verification.
- Add Firebase Authentication/Firestore/Cloud Functions or another secure backend.
- Keep AI API keys on the backend, never in `index.html`.
- Add privacy policy, terms, refund/cancellation process, age-appropriate safeguards, and guardian oversight for account/payment arrangements.
- The tool cards are UI previews; AI responses, PDF parsing, quizzes, and accounts need backend integration.
